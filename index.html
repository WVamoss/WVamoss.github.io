Engineering Pipeline

How WVamoss Edge Architecture Operates

A decoupled, two-tier system designed for ultra-low latency physical edge response and deep cognitive diagnostic reasoning.

TIER 01 // PHYSICAL SENSOR INGESTION

Multi-Sensor Windowing

Direct GPIO/I2C/Serial data acquisition from water quality and industrial sensors. Telemetry is buffered in sliding windows with z-score normalization directly in local memory.

Latency: < 2ms · Buffer: 120 samples
TIER 02 // EDGE ADAPTIVE INFERENCE

SAW-Driven Model Selector

The Simple Additive Weighting (SAW) selector dynamically trades off F1-score (0.25 benefit), Latency (0.35 cost), RAM (0.20 cost), and CPU (0.20 cost) across SNN, CAE, and Isolation Forest models.

Gate Threshold: F1 >= 0.80 · Zero Cloud Trip
TIER 03 // CLAUDE 3.5 SONNET DIAGNOSTICS

Cognitive Reasoning Agent

When anomaly persistence breaches critical gates, contextual telemetry vectors stream to Claude 3.5 Sonnet via Prompt Caching & Tool Use for root-cause analysis and automated actuator dispatch.

Tools: Actuator Relays · Telemetry History

example_pipeline.py Python 3.11 
from wvamoss_edge import EdgeSensorPipeline, SAWEvaluator, ClaudeDiagnostics

# 1. Initialize local sensor acquisition
pipeline = EdgeSensorPipeline(pins={"pH": 17, "EC": 27, "Temp": 22, "DO": 23})

# 2. Select model via Simple Additive Weighting criteria
evaluator = SAWEvaluator(weights={"f1": 0.25, "latency": 0.35, "ram": 0.20, "cpu": 0.20})
model = evaluator.get_optimal_model(target="raspberry_pi_4")

# 3. Stream detection loop
for window in pipeline.stream(interval_sec=1.0):
    anomaly = model.predict(window)
    if anomaly.is_critical:
        # Trigger Claude 3.5 Sonnet diagnostic reasoning agent
        diagnosis = ClaudeDiagnostics.analyze(anomaly, tools=[pipeline.actuators])
        diagnosis.execute_mitigation()
